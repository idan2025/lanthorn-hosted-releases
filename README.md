# Lanthorn Hosted

Downloads of **Lanthorn Hosted**, the app for playing on [Lanthorn hosting](https://lanthorn.cloud):
sign in, join your servers and your friends' from the tray, and invite guests
for as long as you choose.

Get it from the [latest release](https://github.com/idan2025/lanthorn-hosted-releases/releases/latest),
or from [lanthorn.cloud/download](https://lanthorn.cloud/download/).

| System | File |
| --- | --- |
| Windows | `Lanthorn-Hosted_windows_x64-setup.exe` |
| macOS (Apple silicon and Intel) | `Lanthorn-Hosted_macos_universal.dmg` |
| Linux, any distribution | `Lanthorn-Hosted_linux_x86_64.AppImage` |
| Debian, Ubuntu | `Lanthorn-Hosted_linux_x86_64.deb` |
| Fedora, openSUSE | `Lanthorn-Hosted_linux_x86_64.rpm` |

Installed copies update themselves from here. Every update is signed, and the
app installs only an update whose signature matches the key it was built with.

This repository holds releases only. The free, open-source Lanthorn launcher for
running your own servers is at [idan2025/gaming-platform-prns](https://github.com/idan2025/gaming-platform-prns).
